# 검토 강화

현재 흐름에서 문서를 만드는 관련 작업 하나를 고른다. 기존 AI 검토 작업이 있다면 그 작업을 우선한다. 사용자가 지목한 항목만 원본 자료와 대조하도록 그 작업 지침을 수정한다. 항목이 누락되거나 충돌하면 추측하지 않고 검토 의견에 표시하도록 한다. 기존 산출물과 다른 작업의 목적을 보존한다. 사용자가 단계 추가를 직접 요청했을 때만 새 단계를 제안한다. 사용자 승인 단계와 입력 연결을 보존한다.
