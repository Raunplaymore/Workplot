# Workplot 글자 크기

기준은 브라우저 기본 16px이며, 실제 크기는 rem으로 정의한다. 화면 확대와 브라우저 기본 글자 크기를 따른다.

| 역할           | 기본 크기 | 적용 위치                                         |
| -------------- | --------- | ------------------------------------------------- |
| 노드 보조 문구 | 11px      | 담당자·단계 번호, 결과 파일명, 변경안 와이어 범례 |
| 노드 제목      | 12px      | 편집 캔버스, 변경안 미리보기, 모바일 작업 순서    |
| 보조 정보      | 12px      | 상태, 시간, 버전                                  |
| 기본 UI        | 13px      | 버튼, 표의 값, 목록, 필드 이름, 데스크톱 입력     |
| 섹션 제목      | 16px      | 속성 패널 제목, 문서 비교의 원안·수정안 제목      |
| 화면 제목      | 20px      | 실행 현황, 와이어 편집기, 문서 검토               |
| 읽기 본문      | 16px      | 결과·비교 문서, 라이브러리 결과 미리보기          |

기본 UI의 행간은 1.45, 제목은 1.3, 읽기 본문은 1.7이다. 800px 이하 화면에서도 입력 필드는 기본 16px로 표시한다. 글자 크기와 클릭 영역은 별도로 조절한다.

토큰은 [global.css](../../apps/web/src/global.css)에 정의한다.

캔버스의 노드 글자 크기는 배율 100% 기준이다. 확대·축소하면 노드와 텍스트가 함께 변한다.

편집 노드는 폭 160px, 안쪽 여백은 상하 10px·좌우 12px다. 한 줄 제목의 기본 높이는 약 79px이며, 긴 제목은 줄을 바꿔 높이를 늘린다. 연결 단자는 12×12px다. 변경안 미리보기 노드는 140×58px다.
